# Restore drills

Generated by `make restore-drill GAME=<game> RECORD=1` (`scripts/restore-drill.py`). Each row restores the
latest restic snapshot from S3 into a temporary PVC, checks the catalog paths, and deletes it.
**Total** is apply to verified data (includes PVC provisioning and image pull); **restic** is the restore alone.

The monthly `<game>-restore-drill` CronJob runs the same restore and checks automatically; its result line
(`RESULT {...}`) is in the Job log for 3 days: `kubectl -n <game> logs job/<job> | grep RESULT`.
This table holds the drills recorded by hand. The last 30 days of drills (manual and monthly, with result and
duration) stay in Prometheus: Grafana **AsunBoid**, row **Restore drills**, and a line in the weekly Discord summary.
